## Summary
The Daily Display Timetable feature introduces a comprehensive horizontal timeline view for managing all teacher aide assignments for a single day. It leverages a drag-and-drop interface where users can pull task templates from a "Task Bank" or unassigned tasks from a "Relief Pool" panel (fixed on the right) onto the aides' schedules (scrolling horizontally). The system handles overlapping assignments by rendering them as thin strips and visually indicates aide absences.

## Technical Context

**Constraints**: Offline-capable; Local SQLite persistence; WCAG AA compliance.
**Scale/Scope**: ~10-20 aides displayed per day; ~100-200 tasks in bank.
